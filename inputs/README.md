`materials_canonical.csv` is a derived table of official OSC pipeline values (canonical-band n_band,
N(E_F), official A_d and Pairing Index) for 22 materials. It contains C2DB UIDs only; no C2DB data
dump. Licence: **CC-BY-NC 4.0** (non-commercial). Credits: Haastrup et al. (2018), Gjerding et al. (2021),
and FINAL-Bench/OSC-Superconductor. See ../CITATIONS.md.
